Le principe

Un socle fonctionnel commun — vert, rouge, orange, bleu — qui ne change jamais : un vert veut dire « validé » partout dans la plateforme, quel que soit le profil. Par-dessus, une couleur d'identité propre à chaque profil, qui colore la barre de navigation, les boutons d'action principaux et les états actifs. Résultat : on sait en un coup d'œil dans quel espace on se trouve, sans jamais avoir à réapprendre le sens des couleurs.

6 · Variables CSS prêtes à l'emploi

:root {
  /* Socle fonctionnel — identique partout */
  --success:#2E9E5B;  --success-bg:#DFF3E7;  --success-fg:#1E6B3E;
  --danger: #D93A3A;  --danger-bg: #FBE0E0;  --danger-fg: #96201F;
  --warning:#E8963C;  --warning-bg:#FBEEDB;  --warning-fg:#8A5410;
  --info:   #3B82C4;  --info-bg:   #DEEBF7;  --info-fg:   #1E5585;

  /* Neutres */
  --text-strong:#1B1830; --text:#2C2A38; --text-muted:#6B6478;
  --text-disabled:#A8A2B4; --border:#E4E0EA; --surface:#FFFFFF;

  /* Rayons et ombres */
  --r-field:10px; --r-card:16px; --r-pill:999px;
  --shadow:0 2px 10px rgba(40,30,80,.07);
  --shadow-hover:0 6px 20px rgba(40,30,80,.12);
}

/* Identité par profil — appliquée sur <body data-role="..."> */
[data-role="superadmin"] { --brand:#3B3470; --brand-dark:#2A2552; --brand-pale:#E4E3EF; --page:#F2F2F8; }
[data-role="manager"]    { --brand:#7F77DD; --brand-dark:#5B51C4; --brand-pale:#EFECFB; --page:#F4F2ED; }
[data-role="member"]     { --brand:#D85A30; --brand-dark:#993C1D; --brand-pale:#F8DDD3; --page:#FAECE7; }
Mise en œuvre : un seul attribut data-role sur le <body> suffit à basculer tout l'univers visuel. Aucun composant n'est dupliqué : les boutons, cartes et navigations utilisent var(--brand), et changent automatiquement selon le profil connecté.
