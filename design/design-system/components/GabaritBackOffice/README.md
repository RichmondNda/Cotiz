# GabaritBackOffice

Gabarit back-office partagé par le super-admin (indigo) et le gestionnaire (violet).

- Barre latérale 240 px (72 repliée, icônes seules), barre supérieure 64 px, contenu limité à 1280 px sur fond `page`.
- Barre latérale : logo ; côté gestionnaire, l'association courante ; entrées icône + libellé, active en `brand-pale` / `brand-dark` / 600 ; compteurs orange ; en bas paramètres, aide, repli.
- Barre supérieure : fil d'Ariane, recherche globale, cloche avec compteur, avatar et menu. En-tête de page : H1, sous-titre, actions à droite (primaire le plus à droite).
- Tablette < 1024 : barre repliée. Mobile < 768 : menu tiroir via hamburger.
