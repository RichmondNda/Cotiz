# Superpositions

Modales, confirmation renforcée, menu contextuel, infobulle, panneau latéral et feuille basse.

- Modale de confirmation 420 px : titre = question explicite qui nomme l'objet ; corps = conséquence ; bouton = le verbe (jamais « OK »). Modale de formulaire 560 px.
- Confirmation renforcée (suspendre une association, supprimer un projet avec paiements) : taper le nom de l'objet active le bouton.
- Panneau latéral 480 px depuis la droite sur voile `overlay` ; plein écran depuis le bas sur mobile.
- Menu 220 px, action destructive en dernier, séparée, en `danger`. Infobulle `text-strong`, 12 px, délai 300 ms.
