# GabaritSouscripteur

Gabarit souscripteur, mobile d'abord.

- Barre supérieure légère, colonne unique, navigation basse à 4 entrées (Accueil, Projets, Historique, Profil), bouton flottant corail « Déclarer un paiement » au-dessus.
- Cibles ≥ 44 px, un montant dominant par écran, action principale pleine largeur au pouce.
- Desktop : la navigation basse devient une barre latérale, contenu centré sur 960 px, projets en grille de 2.
