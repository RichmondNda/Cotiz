# Graphiques

Visualisation de données : barres attendu / reçu, anneau de taux, courbe cumulative, barre de progression.

- Barres groupées : attendu en `border`, reçu en `brand` ; période en cours en transparence.
- Anneau : couleur de statut selon seuil (≥ 80 % `success`, 50–80 % `warning`, < 50 % `danger`).
- Courbe cumulative (souscripteur) : aire légère sous la courbe, objectif en pointillé.
- Barre de progression : 8 px, `r-pill`. Infobulle au survol de chaque point ; montants abrégés sur les axes (0,5M, 1M), complets dans les infobulles.
