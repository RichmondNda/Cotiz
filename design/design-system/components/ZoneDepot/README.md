# ZoneDepot

Dépôt d'une preuve de paiement ou d'un logo.

- Bordure pointillée, icône, texte, formats acceptés (JPG, PNG, PDF · 5 Mo).
- États : repos, survol / glisser (`brand-pale`), erreur, envoi en cours (barre de progression), fichier déposé (vignette + nom + « Retirer »), désactivé.
- Mobile : ouvre directement le choix appareil photo / galerie.
