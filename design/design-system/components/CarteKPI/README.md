# CarteKPI

Indicateur clé : pastille d'icône + libellé, valeur en grand, ligne de contexte.

- Cliquable : mène vers la liste filtrée correspondante ; survol `shadow-hover`.
- Pastille : `brand-pale` par défaut, ou ton de statut quand le chiffre en est un (à valider = alerte, retards = erreur).
- Grille : 3 ou 4 par ligne desktop, 2 tablette, 1 mobile (ou défilement horizontal). Chargement : squelette de même forme.
