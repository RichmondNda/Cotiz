# EtatsVides

États vides, erreur, fonction à venir et squelettes de chargement.

- Premier usage : icône, explication, bouton d'action, ton encourageant. Vide positif : icône verte (« Rien à valider » est une bonne nouvelle).
- Vide de recherche : rappel du terme + « Effacer la recherche ». Erreur : message humain + « Réessayer », le reste de la page reste utilisable.
- Chargement : squelettes à la forme du contenu final, jamais de spinner plein écran. Fonction V2 : badge « Bientôt disponible ».
