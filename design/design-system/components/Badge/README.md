# Badge

Statut d'un objet, toujours avec un libellé texte — la couleur seule ne porte jamais l'information.

- Tons : `--success`, `--warning`, `--danger`, `--info`, neutre (défaut), `--brand` (identité : « Fonds d'entrée », plan).
- Respecter la table de correspondance : échéance à venir = info, déclarée ou partielle = alerte, payée = succès, en retard = erreur ; projet brouillon / terminé = neutre ; association suspendue = erreur ; demande à traiter = alerte.
- `cz-count` : compteur d'onglet ou de menu, orange quand une action attend.
