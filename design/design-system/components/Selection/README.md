# Selection

Case à cocher, interrupteur, contrôle segmenté et compteur.

- Case 20×20, `r-xs` ; cochée : fond `brand`, coche blanche. Toute la ligne (`cz-check`) est cliquable.
- Interrupteur uniquement pour les réglages à effet immédiat (notifications, relances).
- Contrôle segmenté pour 2 à 4 choix exclusifs visibles (dates fixes / cycle roulant, vue cartes / tableau).
- Compteur pour les petites quantités entières (nombre de souscripteurs requis).
