# Navigation

Onglets, indicateur d'étapes, fil d'Ariane, puces de filtre et pagination.

- Onglets soulignés `brand`, synchronisés avec l'URL ; compteur orange quand une action attend ; mobile : défilement horizontal, onglet actif centré.
- Étapes : terminées en `success` (cliquables pour revenir), courante en `brand` ; mobile : « Étape 3 sur 6 — Calendrier » + barre de progression.
