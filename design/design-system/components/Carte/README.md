# Carte

Conteneur de base : blanc, `r-card`, `shadow`, padding 24 (16–18 sur mobile).

- Variantes : standard, contour (`--flat`), teintée (`--tinted`), grande souscripteur (`--lg`), fantôme (`--ghost`, « + Nouveau projet » en fin de grille).
- Carte cliquable (`.is-clickable`) : survol `shadow-hover`, focus anneau 3 px `brand`, sélection contour 2 px `brand` (cartes de choix de l'onboarding).
- `cz-tile` : tuile de chiffre de la charte sur fond clair d'identité ou de statut.
