# Typographie

Échelle typographique complète : Poppins pour tout ce qui titre, commande ou chiffre ; Inter pour le texte et les tableaux.

- Un seul H1 (`page-title`, 28 px) par écran applicatif ; `display-hero` (44 px) est réservé au héros de la landing.
- Le montant dominant d'un écran prend `amount-hero`, `amount-kpi` ou `amount-card` selon le contexte ; format « 25 000 F », espace fine, sans décimales (`Cotiz.formatFCFA`).
- En-têtes de tableau en `overline` (majuscules, `text-muted`).
- Polices Google Fonts (Poppins 400–700, Inter 400–600), chargées par `bundle.css`.
