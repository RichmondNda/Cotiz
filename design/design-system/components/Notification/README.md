# Notification

Élément de notification.

- Non lue : fond `brand-pale`. Icône sur pastille colorée selon le type (échéance = alerte, validé = succès, rejeté = erreur, contrat = identité).
- Clic : marque comme lue et ouvre l'écran d'action. Groupement « Aujourd'hui / Cette semaine / Plus ancien ».
