# CarteSynthese

Blocs de l'accueil souscripteur : synthèse, carte d'action, prochaine échéance, derniers mouvements.

- Synthèse : fond `corail` plein, texte `on-brand`, « Total restant à payer » en `amount-hero` ; ligne `danger-bg` intégrée si retard, `success-bg` si tout est payé.
- Carte d'action : une par contrat à signer, pointillé `warning`.
- Prochaine échéance : montant, projet, date, compte à rebours `info`, bouton « Déclarer un paiement ».
