# Notes persistantes de Claude Code

Mémoire de travail de Claude entre les sessions sur le dépôt Cotiz. **À lire au début de chaque session.**

| Fichier | Contenu |
|---|---|
| `apprentissages.md` | Journal de ce qui a été appris sur le projet : architecture, conventions, commandes, pièges |
| `decisions.md` | Décisions techniques prises en mode autonome, avec leur raison et l'option retenue |
| `a-verifier.md` | Points incertains, ou actions sensibles qui attendent l'accord d'un humain |

Règles :
- Seulement des faits vérifiés dans le code ou par une commande, avec leur source. Pas de suppositions.
- Une information qui change : on met à jour l'entrée existante (avec la date de mise à jour), on ne la duplique pas.
- Ces notes ne remplacent pas la référence : `CLAUDE.md` et `docs/` (`docs/specs/` est normatif) restent prioritaires.
  Une décision de projet se consigne dans `docs/decisions.md` ou un ADR (`/adr`), pas ici.
