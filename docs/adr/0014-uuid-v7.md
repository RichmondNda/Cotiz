# ADR 0014 · UUID v7 générés par l'application

**Statut :** adopté · 2026-09-29

## Décision

Identifiants triables par date, non devinables, générables côté client pour l'idempotence.

## Pourquoi

PostgreSQL 16 n'a pas `uuidv7()` ; génération dans `packages/domain`.

## Alternatives écartées

Séquences (énumérables) ; UUID v4 (non triables).
