# ADR 0013 · Logique métier partagée dans `packages/domain`

**Statut :** adopté · 2026-09-29

## Décision

Échéancier, répartition, statuts et argent : fonctions pures utilisées par le front et le back, vecteurs de test normatifs.

## Pourquoi

Ce que la maquette montre est exactement ce que le serveur calcule.

## Alternatives écartées

Double implémentation front/back.
