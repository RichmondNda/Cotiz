## Étapes

Une étape = une PR. Commande : `/etape 2.5 <n>`.

### Étape 1 · Tables et canaux

`notifications`, `deliveries` ; interface `NotificationChannel` ; canaux `in_app` et `manual` ; routeur lisant la matrice de `events.yaml`.

**Vérification :** Un canal absent est ignoré sans erreur

### Étape 2 · Consommateurs

Paiement déclaré / validé / rejeté / annulé, inscription, compte activé, demande de réinitialisation, demande de création ; `dedupe_key`, regroupement des déclarations.

**Vérification :** Un paiement validé → exactement une notification

### Étape 3 · API

`nt.list` (+ compteur en cache Redis), `nt.read` (individuel et global).

**Vérification :** Compteur cohérent après lecture

### Étape 4 · Rappel J-3

Tâche `installments.due-soon` (in-app).

**Vérification :** Test avec horloge simulée
