## Étapes

Une étape = une PR. Commande : `/etape 4.3 <n>`.

### Étape 1 · Tables

`reminder_rules`, `reminder_runs` (unique par règle, échéance et jour).

**Vérification :** Migrations

### Étape 2 · Règles

`rm.rules` : déclencheur, décalage, canaux (in_app, push).

**Vérification :** Tests

### Étape 3 · Évaluation quotidienne

`reminders.evaluate` par fuseau : rappels in-app/push (`auto_sent`) + entrées `to_handle` avec message prêt.

**Vérification :** Relancer deux fois le même jour ne crée qu'un rappel

### Étape 4 · File et envoi manuel

`rm.queue` (liste, `handled` / `dismissed`), `rm.send` (relance ciblée), `rm.hist`.

**Vérification :** La file liste exactement les retards sans relance du jour
