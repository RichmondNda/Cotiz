## Étapes

Une étape = une PR. Commande : `/etape 3.3 <n>`.

### Étape 1 · Aperçu de répartition

`me.alloc` via `proposeAllocation()` (et appel local côté front).

**Vérification :** Vecteurs `allocation.json` via l'API

### Étape 2 · Déclaration

`me.declare` : `Idempotency-Key`, preuve `clean` ou référence, `validateAllocation()`, `amount_exceeds_remaining`, inscription active ; transaction de architecture/04 §4.4 ; `payment.declared`.

**Vérification :** Double envoi → un seul paiement ; déclaration concurrente sur la même échéance → la seconde voit le reste réduit

### Étape 3 · Suivi

`me.payment` : statut, répartition, motif de rejet.

**Vérification :** Réponse conforme

### Étape 4 · Bout en bout

Playwright : Moussa déclare 75 000 F (3 échéances) avec photo → Awa valide → les 3 cases passent à « Payée » → Moussa voit la notification.

**Vérification :** Test vert en recette
