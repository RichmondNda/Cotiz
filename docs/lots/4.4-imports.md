## Étapes

Une étape = une PR. Commande : `/etape 4.4 <n>`.

### Étape 1 · Tables

`import_jobs`, `import_rows`.

**Vérification :** Migrations

### Étape 2 · Analyse

`im.flow` : fichier CSV/XLSX (exceljs), détection des colonnes dans le worker.

**Vérification :** Fichier de 5 000 lignes sans bloquer l'API

### Étape 3 · Mappage et correction

`im.steps`, `im.read` : catégories ready / existing / error / duplicate.

**Vérification :** Tests

### Étape 4 · Exécution

`im.commit` : réutilise le cas d'usage d'inscription ligne par ligne ; lien final vers « Codes à remettre » et fiche imprimable groupée (PDF multi-fiches rendu côté navigateur).

**Vérification :** Même résultat qu'une saisie unitaire

## Intégration front

- Assistant d'import en 4 étapes avec progression (SSE si le lot 4.2 est terminé, sinon interrogation toutes les 2 s).
- Basculer les endpoints du lot avec `/bascule <id>` : `im.flow`, `im.steps`, `im.read`, `im.commit`.
