## Étapes

Une étape = une PR. Commande : `/etape 5.2 <n>`.

### Étape 1 · Tables

`api_keys`, `webhook_endpoints`, `webhook_deliveries`.

**Vérification :** Migrations

### Étape 2 · Clés d'API

`dev.keys` : clé affichée une fois, hachée, portée, limitation par plan ; authentification `Authorization: Bearer ck_…`.

**Vérification :** Clé révoquée → 401

### Étape 3 · Webhooks sortants

`dev.webhooks` : événements choisis, signature HMAC-SHA256, reprise 1 min → 24 h, journal des envois.

**Vérification :** Signature vérifiable par un script d'exemple

### Étape 4 · Analytique

`rp.analytics` : tableaux par association.

**Vérification :** Tests
