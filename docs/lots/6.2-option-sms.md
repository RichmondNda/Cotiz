## Étapes

Une étape = une PR. Commande : `/etape 6.2 <n>`.

### Étape 1 · Canal

Adaptateur SMS derrière `NotificationChannel`, repli automatique sur `manual` en cas d'échec ; `features.channel_sms`.

**Vérification :** Fournisseur coupé : codes toujours remettables à la main

### Étape 2 · Usages

Envoi automatique du code d'activation et des rappels ; suivi dans `deliveries` (coût).

**Vérification :** Tests

### Étape 3 · Garde-fous

Identifiant d'expéditeur, plafonds par association, heures calmes.

**Vérification :** Tests
