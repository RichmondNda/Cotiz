## Objectif

Le souscripteur saisit le code remis par son gestionnaire, choisit son mot de passe et gère son profil ; le gestionnaire traite les mots de passe oubliés.

## Étapes

Une étape = une PR. Commande : `/etape 3.1 <n>`.

### Étape 1 · Parcours d'activation souscripteur

Lien `/activer?t=<téléphone>` (depuis le message ou le QR) : téléphone pré-rempli, saisie tolérante du code `XXXX-XXXX` (casse, tiret, espaces), appel de `auth.activate` (lot 1.1), onboarding souscripteur, notification au gestionnaire.

**Vérification :** Test Playwright avec un code réel issu du lot 2.3 ; le compte disparaît de « Codes à remettre »

### Étape 2 · Profil

`me.profile` : lecture, modification, changement de mot de passe (révoque les autres sessions).

**Vérification :** Tests

### Étape 3 · Réinitialisations des souscripteurs

`as.resets` : demandes des souscripteurs de l'association, émission d'un code 6 chiffres affiché une fois avec message prêt ; notification in-app aux gestionnaires à chaque demande.

**Vérification :** Parcours complet : mot de passe oublié → code émis par Awa → nouveau mot de passe
