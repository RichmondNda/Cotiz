## Étapes

Une étape = une PR. Commande : `/etape 3.5 <n>`.

### Étape 1 · Parcours complets

Playwright sur les trois espaces : demande → approbation → onboarding → projet → inscription → code remis → activation → déclaration → validation → notification.

**Vérification :** Vert en recette

### Étape 2 · Sans fournisseur

Test d'acceptation dédié : aucune variable de canal externe définie, toute la boucle passe.

**Vérification :** Vert

### Étape 3 · Charge et sécurité

k6 (grille, tableau de bord, 100 déclarations, validations concurrentes) ; OWASP ZAP ; revue des en-têtes et de la CSP.

**Vérification :** Objectifs de architecture/09 tenus ; aucune alerte ZAP haute

### Étape 4 · Sauvegarde et reprise

pgBackRest/WAL-G + `mc mirror` vers le second VPS ; restauration complète chronométrée ; runbooks (restauration, incident, suspension d'urgence, fuite suspectée) dans `docs/runbooks/`.

**Vérification :** Restauration < 1 h

### Étape 5 · Production

`infra/compose/production.yml`, migrations en tâche préalable, handlers simulés exclus du build (`NUXT_MOCKS=0`), déploiement sur étiquette.

**Vérification :** `/health/ready` en production

### Étape 6 · Première association

Formation du gestionnaire (remise des codes, validation) ; suivi rapproché d'une semaine ; mentions légales validées par un juriste.

**Vérification :** Jalon V1 atteint

## Intégration front

- Handlers simulés exclus de la production (`NUXT_MOCKS=0`, `nitro.ignore`) ; toutes les données simulées retirées de l'interface.
