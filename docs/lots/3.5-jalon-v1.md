## Étapes

Une étape = une PR. Commande : `/etape 3.5 <n>`.

### Étape 1 · Parcours complets

Playwright sur les trois espaces : demande → approbation → onboarding → projet → inscription → code remis → activation → déclaration → validation → notification.

**Vérification :** Vert en local, contre api et worker réels

### Étape 2 · Sans fournisseur

Test d'acceptation dédié : aucune variable de canal externe définie, toute la boucle passe.

**Vérification :** Vert

### Étape 3 · Charge et sécurité

k6 (grille, tableau de bord, 100 déclarations, validations concurrentes) ; OWASP ZAP ; revue des en-têtes et de la CSP. Contre la pile locale.

**Vérification :** Objectifs de architecture/09 tenus en local ; aucune alerte ZAP haute

### Étape 4 · Répétition de production en local

`infra/compose/production.yml` lancé en local avec les images construites par la CI : migrations en tâche préalable, handlers simulés exclus du build (`NUXT_MOCKS=0`, `nitro.ignore`), configuration uniquement par variables d'environnement. Ce fichier est celui que le lot 7.1 déploie.

**Vérification :** `/health/ready` répond 200 sur la pile de production locale ; les parcours de l'étape 1 y passent
