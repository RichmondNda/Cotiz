## Étapes

Une étape = une PR. Commande : `/etape 4.7 <n>`.

### Étape 1 · TOTP

Table `mfa_factors` ; `auth.mfa` : enrôlement (QR généré côté serveur), confirmation, codes de secours, vérification ; obligatoire pour le personnel plateforme (remplace la liste d'IP).

**Vérification :** Sans second facteur, un compte plateforme ne se connecte plus

### Étape 2 · Personnel plateforme

`pf.staff` : invitation par code `staff_invite` affiché.

**Vérification :** Tests

### Étape 3 · Audit

`pf.audit` : filtres, export ; export JSON de ses données depuis le profil.

**Vérification :** Tests de permission
