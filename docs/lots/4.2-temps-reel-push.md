## Étapes

Une étape = une PR. Commande : `/etape 4.2 <n>`.

### Étape 1 · Tables

`message_templates`, `notification_preferences`, `push_subscriptions`.

**Vérification :** Migrations

### Étape 2 · SSE

`nt.stream` : SSE authentifié, Redis Pub/Sub entre réplicas, reprise `Last-Event-ID`, battement de cœur 25 s.

**Vérification :** Notification visible < 2 s sans recharger

### Étape 3 · Web Push

Clés VAPID générées (CLI) ; `me.push` ; canal `push` (bibliothèque `web-push`) ; nettoyage 404/410 ; heures calmes ; file `notify-push`.

**Vérification :** Push reçu appareil verrouillé (Android Chrome, iOS 16.4+ en PWA installée)

### Étape 4 · Préférences et modèles

`me.prefs` par type et canal disponible ; modèles par événement et langue.

**Vérification :** Désactiver un type coupe le push, pas l'in-app obligatoire

## Intégration front

- SSE à la place de l'interrogation ; service worker Nuxt (PWA) ; invitation à activer les notifications ; écran des préférences (canaux externes masqués).
- Basculer les endpoints du lot avec `/bascule <id>` : `nt.stream`, `me.push`, `me.prefs`.
